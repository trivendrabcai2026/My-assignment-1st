Assignment 1 – What Happens Between Typing a URL and Seeing the Page?
When we type a URL (website address) into a web browser, such as Google Chrome, and press Enter, several steps take place before the webpage appears on our screen.
Steps involved:
1. URL Entry: We type the website address (URL) into the browser and press Enter.
2. DNS Lookup: The DNS (Domain Name System) converts the domain name into an IP address of the web server.
3. Establishing Connection: The browser connects to the web server using TCP and, for HTTPS websites, establishes a secure connection using TLS.
4. HTTP Request: The browser sends an HTTP request to the server to ask for the webpage.
5. Server Response: The server processes the request and sends back the required files, such as HTML, CSS, JavaScript, and images.
6. Rendering the Page: The browser reads the files, applies styles, runs JavaScript, and displays the webpage.
7. Webpage Display: Finally, the webpage appears on the screen, and the user can interact with it.
